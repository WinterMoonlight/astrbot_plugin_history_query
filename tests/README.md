# 测试计划

当前尚无插件功能实现，本目录暂不包含自动化功能用例，不以“零测试通过”作为验收结果。

后续按实现顺序加入合成数据测试：

- 单执行槽位、有限等待队列、整轮累计排队 5 秒与执行 5 秒分别计时。
- 取消、超时、进程回收、队列退出后的资源释放。
- 每个入口的权限校验、跨平台同号、私聊/群聊入口区别、撤权与未知成员状态。
- 同批和并发工具调用、已有任务完成、新轮次隔离、版本接入失败只停用查询。
- 两类只读读取器、宿主数据及结构不变、SQL 参数与输入边界。
- 多会话轮流读取、稳定游标、续查、删除、恢复或 ID 重用、上下文补读。
- 时间信息不足、预算耗尽、部分结果和来源标注。

不在自动测试中使用真实聊天记录、生产凭据、真实消息发送或外部模型调用。
